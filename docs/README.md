# Tasarım belgeleri

| Klasör | İçerik |
|---|---|
| `akis-semasi/` | Sistemin çalışma mantığını gösteren akış şemaları |
| `er-diyagrami/` | Veritabanı ER diyagramı. `.drawio` dosyası [app.diagrams.net](https://app.diagrams.net) ile açılıp düzenlenebilir |
| `wireframe/` | Sayfa yerleşim taslakları (yalnızca yerleşim, renk yok) |
| `mockup/svg/` | Ayrıntılı arayüz tasarımları. Figma'ya sürükleyip bırakınca tüm katmanlar düzenlenebilir |
| `mockup/png/` | Mockup'ların hızlı önizlemesi |
| `sunum/` | Ara sunum dosyası |
| `rapor/` | Proje öneri formu ve proje anlatım belgesi |
